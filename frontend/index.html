4096-bit vectors

Each token is a random 4096-bit binary vector. Meaning emerges from XOR, majority vote, and Hamming distance — pure algebra.

BindXOR — associates concepts. Invertible: bind(A,bind(A,B)) = B
BundleMajority vote — superposes a set. Similar to all, identical to none.
PermuteBit rotation — encodes position. Same word, different slot → different vector.
SimilarityNormalized Hamming ∈ [0,1]. ~0.5 = orthogonal. 1.0 = identical.
